# Student Understanding Checklist

The student should be able to explain:
1. What problem does Mission Dark Sky address?
2. Why doesn't the system simply turn lights off?
3. What inputs does the Adaptive Lighting Engine use?
4. How is target lighting calculated?
5. What does server code do versus client code?
6. Why is configuration separated from algorithms?
7. What happens when a person enters the parking lot?
8. How are energy/environment effects represented?
9. Which values are simulated rather than measured?
10. What parts were created with AI assistance?
11. How was AI-generated code reviewed and tested?
12. What would be needed to connect physical sensors?
