# Initial Scenarios

1. Empty Parking Lot — late night, no activity; low baseline.
2. Pedestrian Arrives — lighting increases gradually.
3. Multiple Activity — people/vehicles increase demand.
4. Community Event — higher lighting demand.
5. Event Ends — lighting gradually returns toward baseline.
6. Sunrise — ambient light increases and artificial demand decreases.

These are simulation scenarios, not real-world lighting requirements.
