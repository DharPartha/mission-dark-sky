# UI/UX Specification

## Goals
The interface should make the engineering behavior understandable at a glance.

## Initial UI
Show:
- current scenario
- current people
- current vehicles
- ambient light
- event state
- current lighting
- target lighting
- basic impact metrics

## Controls
Provide simple controls for:
- starting scenarios
- changing simulated activity
- changing time
- changing weather
- toggling event state

## Visual Feedback
The user should be able to see:
- lights brighten
- lights dim
- affected zones
- current versus target state

## Design Principle
Do not make the UI look like a generic dashboard detached from the simulation.
The data should correspond directly to visible behavior in the Smart Town.
