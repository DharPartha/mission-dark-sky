# AI Development Workflow

## Source of Truth
The docs/specs directory defines expected behavior.

## Cursor Workflow

### Step 1
Ask Cursor to read AGENTS.md, then only the specs its task table lists for this milestone.

### Step 2
Ask for a plan before implementation.

### Step 3
Approve one milestone.

### Step 4
Implement only that milestone.

### Step 5
Test in Roblox Studio.

### Step 6
Review changed files.

### Step 7
Update documentation if behavior changed.

## Rule
Do not ask an AI agent to build the entire project in one request.

## Student Understanding
For every significant module, the student should be able to explain:
- purpose
- inputs
- outputs
- algorithm
- dependencies
- test method
- limitations
