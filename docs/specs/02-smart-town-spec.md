# Smart Town World Specification

## Purpose
Create a compact virtual community that demonstrates different outdoor-lighting contexts.

## Areas
1. Parking lot
2. School
3. Main street
4. Sports field
5. Residential area
6. Store/business

## Design Principle
Each area should have a different reason for needing light.

## Initial Build
Only the parking lot is required for the first milestone.

## Town Expansion
After the parking lot system works, reuse the same lighting architecture across additional
zones rather than creating separate lighting logic for every location.

## Visual Goal
The environment should clearly communicate:
- nighttime conditions
- illuminated areas
- people/activity
- changing lighting levels
- before/after comparison

The town does not need to be geographically accurate or large.
