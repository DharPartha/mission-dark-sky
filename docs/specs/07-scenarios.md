# Scenario Lab Specification

## Purpose
Provide repeatable situations that demonstrate how the adaptive system responds.

## Required Scenarios
1. Empty Parking Lot
2. Single Pedestrian
3. Multiple Pedestrians
4. Vehicle Arrival
5. Community Event
6. Event Ends
7. Rain
8. Sunrise

## Scenario Requirements
Each scenario should:
- define starting conditions
- define changes over time
- show lighting response
- show impact metrics
- be repeatable

## Demonstration Scenario
A recommended first demo:
- 11:00 PM: empty lot
- pedestrian arrives
- vehicle arrives
- activity increases
- event begins
- event ends
- activity leaves
- system returns toward baseline
- sunrise reduces artificial demand

The exact clock times and simulation coefficients are configurable.
