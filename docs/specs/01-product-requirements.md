# Product Requirements

## MVP
The MVP must demonstrate one complete adaptive-lighting loop.

### Required
- A parking-lot environment
- Four controllable lighting fixtures
- Simulated people
- Simulated vehicles
- Time-of-day input
- Ambient-light input
- Adaptive lighting calculation
- Gradual lighting transitions
- Basic impact metrics
- At least three repeatable scenarios

### Quality Requirements
- The simulation must be understandable without reading source code.
- Lighting changes must be visibly noticeable.
- The same scenario should produce reproducible results.
- Simulation parameters must be configurable.
- Important calculations must be separated from presentation code.

### Out of Scope for MVP
- Physical mains-powered hardware
- Cloud backend
- External APIs
- Real municipal lighting control
- Complete town
- Phone sensor integration
