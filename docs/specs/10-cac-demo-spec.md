# CAC Demo Specification

## Demo Goal
Show that Mission Dark Sky is an engineering simulation rather than only a visual game.

## Recommended Demo Story

### 1. Problem
Outdoor lighting is useful, but lighting needs change with activity and conditions.

### 2. Baseline
Show an empty parking lot with fixed lighting.

### 3. Adaptive System
Activate the adaptive lighting engine.

### 4. Change Conditions
Introduce:
- pedestrian
- vehicle
- multiple activity
- event

### 5. Observe
Show lights adapting instead of remaining fixed.

### 6. Measure
Show simulated energy/cost/environment metrics.

### 7. Explain
Show which inputs caused the lighting decision.

## Three-Minute Structure
0:00–0:25 — problem and core question
0:25–1:20 — live adaptive parking-lot demonstration
1:20–2:10 — algorithm and sensor inputs
2:10–2:40 — impact comparison
2:40–3:00 — why it matters and future expansion

## Important
The final demo should show working software and explain the student's engineering decisions.
AI assistance should be disclosed where required and the student should understand the code.
